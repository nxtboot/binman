Binman
======

Binman packages firmware binaries into images described by a devicetree. It is
designed primarily for use with U-Boot and associated binaries such as ARM
Trusted Firmware, but is general enough to be used with other projects.

The project is hosted at https://github.com/nxtboot/binman
